# 계측 (Scatterometry·CD-SEM·Overlay)

## 1. 현재 표준 — in-line 비파괴 요구가 만든 조합

현재 계측 표준은 **광학 scatterometry(OCD)의 in-line 지배 + CD-SEM의 국소 검증 + overlay metrology의 웨이퍼 스케일 통계 관리**다. 이 조합이 표준이 된 전제는 in-line 비파괴 요구다.

CD-SEM은 국소 지점의 절대값 측정에는 강하지만 처리량이 낮고 하전 손상(charging damage)이 있다. Scatterometry는 격자 회절 패턴에서 형상 파라미터를 역산하는 간접 측정이지만, 웨이퍼 전면을 초당 다수 지점 스캔할 수 있어 통계적 프로세스 컨트롤(SPC)에 부합한다는 것이 표준화의 결정적 이유다. 다만 이 방식은 **측정 대상이 주기적 격자여야 한다**는 강한 전제를 요구한다.

Overlay 계측은 image-based(IBO)와 diffraction-based(DBO)가 병용되며, 현세대 예산은 웨이퍼당 2 nm 이하로 요구된다 — 이 숫자 자체가 소자층의 나노시트 정렬 요구에서 역산된 값이다.

## 2. 한계 — 3차원 매장 구조 앞의 2차원 도구

3D 소자에서 정보가 필요한 지점은 표면이 아니라 **매장된 층·홀 내부**다. 광학 scatterometry는 매장 구조에 대해 감도가 급격히 떨어지고, CD-SEM은 표면만 본다. TEM은 원자 스케일 정보를 주지만 파괴 검사이며 웨이퍼 스케일 통계를 만들 수 없다.

**관찰 대상이 3차원 매장 구조로 이동했는데 관찰 도구는 여전히 2차원 표면 중심**이라는 이 불일치가 계측 계층 전체의 가장 큰 관성이다. Scatterometry의 격자 전제 역시 GAA·CFET처럼 비주기적이거나 복잡한 3차원 형상이 늘어날수록 역산 모델의 신뢰도가 떨어지는 근본 제약으로 작동한다.

## 3. 대안 후보

**CD-SAXS(X-ray 산란 계측).** 매장 구조에 대해 감도가 있고 비파괴다. 웨이퍼 스케일 처리량과 spot size가 아직 in-line 표준 대체 수준은 아니지만, 참조 계측(reference metrology)으로 자리잡는 중이다. 상용 처리량 확보가 미해결 과제다.

**E-beam multi-column inspection.** 다수 컬럼을 병렬화해 SEM 처리량 문제를 완화하는 접근으로, AMAT·ASML(Hermes) 등이 개발 중이다. 남은 문제는 컬럼 간 균일도·정렬이며, 단순 물량 증가로는 매장 구조 관찰 문제 자체를 풀지 못한다.

**Hybrid metrology / ML 기반 재구성.** scatterometry + CD-SEM + X-ray를 결합해 각각의 약점을 보완하는 접근. 지도학습으로 형상 파라미터를 역산하는 방식이 도입되고 있으나, 학습 데이터의 참조 진리(ground truth) 확보가 문제다 — 파괴 TEM 결과를 참조로 삼는데 이 자체가 소수 표본이라 통계적 검증이 어렵다.

**In-line 3D tomography / atom probe / X-ray CT.** 매장 구조를 3차원으로 재구성하지만 파괴·반파괴이며, 웨이퍼 스케일 in-line 적용은 아직 요원하다.

## 4. 상위 계층 영향

**매장 구조 관찰 한계가 회로 계층에 built-in self-test(BIST)·on-die sensor 확대를 강제한다.** 웨이퍼 계측만으로 3D 매장 결함을 다 잡지 못하므로, 회로 자체에 지연·전압·온도·에러 카운터를 심어 필드에서 신뢰도를 모니터링하는 설계가 표준화된다 — 회로 면적의 일정 몫이 "계측이 못 보는 것을 회로가 관찰하기 위한 오버헤드"로 사전 배분된다.

**scatterometry의 격자 전제가 소자 계층의 형상 자유도를 간접적으로 제약한다** — 계측 가능한 반복 패턴 위주로 설계 규칙이 수렴하는 압력이 생기며, 이는 [[finfet-gaa-nanosheet]]·[[cfet]] 같은 새 구조가 도입될 때마다 계측 모델을 처음부터 다시 검증해야 하는 지연 요인이 된다.

**학습 데이터 부족(ground truth 희소성)이 ML 기반 계측의 신뢰 구간을 제한한다** — 이는 계측 계층 자체가 다음 세대 소자 구조의 검증 병목이 될 수 있다는 것을 뜻하며, [[hardware-emulation]]처럼 검증 인프라 확충이 먼저 요구되는 다른 계층의 패턴과 유사하다.
