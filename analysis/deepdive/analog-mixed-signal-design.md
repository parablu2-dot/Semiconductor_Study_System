# 아날로그·믹스드시그널 설계

## 1. 현재 표준 — 디지털과 30년째 분리된 흐름

디지털이 RTL+표준셀+P&R+STA로 자동화된 것과 대조적으로, 아날로그·믹스드시그널은 **schematic 기반·SPICE 검증·수작업 레이아웃**이 여전히 표준이다. 이 이원 구조 — 디지털은 자동화, 아날로그는 수작업 — 는 30년 넘게 유지된 통설이다.

## 2. 한계 — 노드 미세화의 편익을 못 받는 회로

아날로그 회로의 성능은 gm/ID·잡음·매칭·headroom 같은 파라미터에 의존하는데, 이들 중 상당수는 미세화와 함께 오히려 열화된다. Vth 변동성 증가([[sram-cell]]에서 다룬 변동성과 같은 계열), 공급전압 축소로 인한 headroom 상실, 배선 저항 증가([[cu-low-k-interconnect]] 참조)로 인한 passive 소자 열화가 겹쳐, **아날로그는 성숙 노드(28 nm·22 nm·16 nm)에서 설계하는 것이 오히려 경제적**이라는 판단이 산업 통설이 됐다.

이는 소자·공정 계층에서 강제된 "연산 다이(선단 노드) + I/O·아날로그 다이(성숙 노드)의 이원화"와 정확히 맞물린다 — 아날로그 설계의 정체가 아니라, 재료·소자 계층의 물성 변화가 아날로그 회로에 불리한 방향으로 작동한 결과라는 것이 이 한계의 본질이다.

## 3. 대안 후보

**아날로그 자동화.** Cadence Virtuoso ADE·Synopsys Custom Compiler에 통합된 최적화·ML 기반 sizing·layout 자동화 시도가 계속되고 있으며, 학계에서는 완전 자동 아날로그 합성 연구가 30년 넘게 이어졌다. 미해결은 아날로그 성능이 layout parasitic·matching에 극단적으로 민감해 topology 선택 → sizing → layout → post-layout 시뮬레이션의 반복 루프를 완전 자동화한 사례가 상용 규모로는 없다는 것 — **완전 자동 아날로그 합성은 30년 전 예측이 여전히 유효한 미해결 문제**라는 것이 통설이다.

**성숙 노드 고정 전략의 정착.** 아날로그를 미세화 경쟁에서 아예 빼고 성숙 노드에 고정하는 것 자체가 현재로서는 가장 현실적인 "대안"이다 — 이는 문제를 푸는 것이 아니라 문제가 있는 영역을 회피하는 산업 전체의 합의다.

## 4. 상위/교차 계층 영향

**아날로그·믹스드시그널 이식성 상실이 설계 방법론 계층에 별도 사인오프 흐름을 강제한다.** 디지털 STA·SSTA로는 아날로그·RF 블록의 성능을 검증할 수 없으므로 SPICE·FastSPICE·AMS 시뮬레이터가 별도 흐름으로 병렬 유지되며, 디지털-아날로그 경계에서 co-simulation의 시간·정확도 트레이드오프를 관리하는 것이 검증 아키텍처의 핵심 결정이 된다 — 이것이 이 소주제가 ch4와 ch5 양쪽에서 논의되는 이유다.

**아날로그·디지털 팀 분리가 조직 구조까지 강제한다** — 아날로그 팀·디지털 팀·시스템 팀이 별도 도구 스택으로 유지되도록 강제되며, 이 분리를 극복하려는 unified mixed-signal signoff 시도는 20년째 계속되고 있지만 완결되지 못했다.

**성숙 노드 고정이 패키징 계층에 heterogeneous 통합 요구를 강제한다** — 연산 다이(선단 노드)와 아날로그·I/O 다이(성숙 노드)를 물리적으로 붙이는 방법이 advanced packaging이며, [[chiplet-ucie]]의 부상은 이 계층의 아날로그 이식성 문제에서 직접 파생된 결과다.
